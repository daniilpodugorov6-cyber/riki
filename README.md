# Первый экран — Даниил Рики

Готовая адаптивная вёрстка на HTML, CSS и JavaScript. Установка пакетов не требуется.

## Как открыть

Откройте `index.html` из папки с распакованным архивом. Все изображения и шрифты находятся в `assets` и работают без интернета.

В VS Code можно открыть папку и запустить Live Server. Вариант через терминал: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Состав

- `index.html` — первый экран и окно подготовки обращения.
- `styles.css` — адаптивная сетка, типографика и анимации.
- `script.js` — окно обращения, мобильное меню, копирование сообщения и небольшой параллакс.
- `assets/` — фон, локальные шрифты Inter и favicon.

## Что подключить при продолжении

Сейчас сделан только первый экран. Пункты «Работы», «Этапы», «Стоимость» и «Посмотреть работы» отключены до добавления разделов. В HTML есть комментарии для подключения.

Окно расчёта готовит текст обращения и копирует его; оно не отправляет заявки. Для реального запуска нужно указать Telegram-адрес Даниила и/или подключить обработчик формы.

Обязательных внешних библиотек и CDN нет. Анимации отключаются по системной настройке уменьшения движения. Интерфейс полностью доступен без анимаций.

## Настройки

Цвета меняются в `:root` файла `styles.css`. Основная ширина контейнера — до 1328 px. Мобильная композиция включается при 760 px и меньше. Текст находится в HTML отдельно от фото.
