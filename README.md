# Первый экран — Даниил Рики

Готовая адаптивная вёрстка на HTML, CSS и JavaScript. Установка пакетов не требуется. Слово «клиентов» белое: тонкое подчёркивание появляется через 1,5 секунды после начала показа первого экрана. Синее свечение и шум удалены. Фото статично. Кнопки плавно заполняются светлым фоном при наведении; стрелки не смещаются. Короткая заставка с именем растворяется за 1,05 секунды и работает даже без JavaScript.

## Как открыть

Откройте `index.html` из папки с распакованным архивом. Все изображения и шрифты находятся в `assets` и работают без интернета.

В VS Code можно открыть папку и запустить Live Server. Вариант через терминал: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Состав

- `index.html` — первый экран и окно подготовки обращения.
- `styles.css` — адаптивная сетка, типографика и анимации.
- `script.js` — окно обращения, мобильное меню, копирование сообщения.
- `assets/` — фон, локальные шрифты Inter и favicon.

## Что подключить при продолжении

Сейчас сделан только первый экран. Пункты «Работы», «Этапы», «Стоимость» и «Посмотреть работы» отключены до добавления разделов. В HTML есть комментарии для подключения.

Окно расчёта готовит текст обращения и копирует его; оно не отправляет заявки. Для реального запуска нужно указать Telegram-адрес Даниила и/или подключить обработчик формы.

Обязательных внешних библиотек и CDN нет. Анимации отключаются по системной настройке уменьшения движения. Интерфейс полностью доступен без анимаций.

## Настройки

Цвета меняются в `:root` файла `styles.css`. Основная ширина контейнера — до 1328 px. Мобильная композиция включается при 760 px и меньше. Текст находится в HTML отдельно от фото. Межстрочный интервал заголовка — 100% на компьютере и 104% на телефоне. Тайминги заставки и подчёркивания находятся в `.preloader` и `.headline__accent::after`.

Шрифт Inter: https://github.com/rsms/inter — лицензия SIL Open Font License.

## Видео на мониторе

`assets/monitor.mp4` — оптимизированная запись без звука, с плавным переходом к началу. Видео автоматически повторяется в пределах экрана монитора. Перспектива и положение адаптируются вместе с фото. При запрете автозапуска или системном уменьшении движения остаётся статичное фото. В скрытой вкладке и за пределами экрана воспроизведение приостанавливается.

Фото на ПК вписано целиком в область ниже шапки с отступом справа. Видео сохраняет привязку к экрану. Белый маркер под словом «клиентов» прорисовывается и исчезает с циклом 4,6 секунды.

Фон ПК заполняет весь первый экран без боковых полей (cover, выравнивание справа). Перспектива видео уточнена по наклону рамки монитора.
