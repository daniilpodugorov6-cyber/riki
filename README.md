# Даниил Рики — первый экран

Распакуйте архив целиком и откройте index.html. Видео удобно проверять через Live Server.

Прелоудер удалён. Хедер сдвинут на 20 px вниз. ДАНИИЛ РИКИ — font-weight 600 и letter-spacing −0.07em; подпись с межстрочным интервалом 1.2. Используется прежняя фотография, последняя полностью резкая генерация исключена.

На телефоне: текст и описание → фото с видео без рамки → две кнопки одинакового размера. В мобильном меню Работы, Этапы, Стоимость. Эти пункты и кнопка портфолио отключены до добавления разделов. Форма только подготавливает и копирует сообщение, отправка не подключена.

Видео без звука, автоматический повтор. При запрете автозапуска остаётся фото. Системное уменьшение движения отключает анимации и видео. Шрифты Inter и их лицензия находятся в assets.
