# Даниил Рики — первый экран

Распакуйте архив целиком. Для проверки используйте Live Server в VS Code.

На ПК используется assets/hero-desktop-v2.webp: монитор расположен ниже хедера и выше ноутбука. На мобильном assets/hero-mobile-portrait.webp служит единым вертикальным фоном; верх фотографии плавно растворяется под текстом. Для каждого кадра задана отдельная перспектива видео.

Для замены анимации замените assets/monitor.mp4 (ПК) и assets/monitor-mobile.mp4 (телефоны). Оба ролика проигрываются без звука с автоматическим повтором. Начальный кадр находится в assets/mobile-monitor-poster.webp. Названия файлов выбираются через data-desktop-src и data-mobile-src в index.html.

Мобильное меню открывается на весь экран. Подпись «Веб-дизайнер и разработчик» отображается в одну строку. Пункты Работы, Этапы и Стоимость и кнопка портфолио отключены до добавления разделов. Форма подготавливает сообщение для копирования; отправка не подключена.

Системное уменьшение движения отключает анимации и воспроизведение видео. Шрифты Inter и их лицензия находятся в assets.

На мобильном заголовок набран единым текстом с естественными переносами и жирным акцентом «Разрабатываю сайты». Надпись «Разработка под ключ» уменьшена. Выделение «Беру на себя весь цикл» и анимированное подчёркивание сохранены.
