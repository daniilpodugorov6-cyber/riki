# Даниил Рики — первый экран

Распакуйте архив целиком и откройте index.html. Для проверки видео удобно использовать Live Server.

Последняя версия: логотип из предоставленного SVG, обновлённое фото с чётким монитором, новое видео целиком без звука. Видео повторяется автоматически; при запрете автозапуска остаётся фото. Фото и видео масштабируются вместе. На телефоне отдельная композиция с текстом, кнопкой и карточкой фото ниже. Маркер под словом «клиентов» анимирован по кругу. Системное уменьшение движения отключает анимации и видео.

Пункты будущих разделов и портфолио пока отключены. Форма только подготавливает сообщение и копирует текст, отправка заявок не подключена.

В assets лежат локальные шрифты Inter с лицензией, логотип, фото и видео. Логотип в присланном SVG содержит встроенное растровое изображение.
